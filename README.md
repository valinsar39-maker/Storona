# Сторона Покупателя

Продающий сайт юридической компании «Сторона Покупателя» — независимое юридическое
сопровождение покупателя недвижимости перед сделкой и до регистрации права собственности.

Сайт ориентирован на холодный трафик из Яндекс Директа: закрывает страхи покупателя
перед оплатой, объясняет ценность независимого юриста и собирает заявки.

## Стек

Статический сайт: HTML + CSS + JavaScript, без сборки и зависимостей.
Подключается один шрифт (Inter) через Google Fonts.

## Структура

```
.
├── index.html                  # Главная продающая страница (лендинг)
├── proverka-kvartiry.html      # Юридическая проверка квартиры перед покупкой
├── proverka-prodavca.html      # Проверка продавца недвижимости
├── soprovozhdenie-sdelki.html  # Сопровождение сделки с недвижимостью
├── tarify.html                 # Тарифы
├── contacts.html               # Контакты
├── thanks.html                 # Страница благодарности после заявки
├── privacy.html                # Политика конфиденциальности (шаблон)
├── consent.html                # Согласие на обработку ПДн (шаблон)
└── assets/
    ├── css/style.css           # Дизайн-система и все стили
    ├── js/main.js              # Меню, scroll-reveal, валидация формы, аналитика
    └── img/favicon.svg
```

## Локальный запуск

Откройте `index.html` в браузере или поднимите простой сервер:

```bash
python3 -m http.server 8000
# затем http://localhost:8000
```

## Формы

Бэкенд пока не подключён. При валидной отправке форма имитирует успех и
перенаправляет на `thanks.html`. Логика отправки в `assets/js/main.js`.
Кнопка отправки заблокирована, пока не отмечен чекбокс согласия на обработку ПДн.

## Аналитика (Яндекс Метрика)

В `<head>` каждой страницы есть placeholder для счётчика Метрики. Цели размечены
через атрибуты `data-goal` / `data-goal-view` и вызываются через `ymGoal()` в `main.js`.
